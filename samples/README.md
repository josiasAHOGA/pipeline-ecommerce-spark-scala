# Échantillon de consultation

Ce CSV contient les 1 000 premières lignes du fichier de transactions enrichies de l’exécution vérifiée, sans échantillonnage aléatoire. Il ne doit pas servir à recalculer les totaux globaux. Les 124 751 transactions enrichies complètes sont dans output/parquet/enriched_transactions. Le CSV complet est généré par la commande all.
